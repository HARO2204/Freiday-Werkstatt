# Freiday-Werkstatt

Eine Unterrichtssammlung für den **Freiday** an der Mittelschule (Österreich): Projektideen, druckfertige Arbeitsblätter und Online-Übungen zu den 17 Nachhaltigkeitszielen der Vereinten Nationen.

**Zur Werkstatt:** https://haro2204.github.io/Freiday-Werkstatt/
**Schüleransicht (nur Übungen):** https://haro2204.github.io/Freiday-Werkstatt/#schueler

## Inhalt

| Bereich | Was es gibt |
|---|---|
| Projektideen | je Ziel vier Projektideen (klein, mittel, groß), Ideen-Würfel über alle Ziele |
| Arbeitsblätter | Projektsteckbrief, Ideenfinder, Recherche-Blatt, Team-Vertrag (je 1 Seite A4); Logbuch und Reflexionskarte (1×, 2× oder 3× pro A4) |
| Online-Übungen | Ziel-Detektiv, Wahr oder falsch, Nummern-Profi – für das iPad |
| Ablauf & Planung | fünf Projektphasen und ein Vorschlag für einen Freiday-Vormittag |

## Hinweise

- Alle Texte und Aufgaben sind selbst formuliert. Fremde Inhalte werden nur verlinkt (z. B. [frei-day.at](https://www.frei-day.at/)).
- Die ganze Werkstatt steckt in einer einzigen Datei: `index.html`. Es braucht keine Installation.
- Arbeitsblätter lassen sich direkt aus dem Browser drucken oder als Datei speichern.
